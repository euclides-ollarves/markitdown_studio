# Screenshots Directory

Coloca en esta carpeta las capturas de pantalla de la aplicación para mostrarlas en el `README.md`.

### Nombres recomendados:
- `app_preview.jpg` — Vista principal de la aplicación y zona Drag & Drop.
- `split_view.jpg` — Vista previa de Markdown dividido (Renderizado vs Código).
- `batch_converter.jpg` — Cola de procesamiento por lotes.
- `settings_modal.jpg` — Modal de configuración de modelos de IA / OpenRouter.
