Supported Document Formats & Capabilities

📄 Documents
  • PDF: Structured text, tables, headers, metadata.
  • Word (.docx, .doc): Full styling, lists, headings.
  • PowerPoint (.pptx, .ppt): Slide-by-slide text & shapes.
  • EPub: Complete e-book chapter extraction.
  • Outlook (.msg): Email subjects, headers, bodies.
📊 Data & Spreadsheets
  • Excel (.xlsx, .xls): Sheet-to-Markdown tables.
  • CSV / TSV: Clean Markdown tables.
  • JSON & XML: Structured formatted blocks.
  • Jupyter (.ipynb): Code & markdown cells.
🎙️ Audio & 🖼️ Images
  • Audio (.mp3, .wav): Speech transcription & EXIF.
  • Images (.png, .jpg): EXIF metadata + Vision OCR.
  • ZIP Archives: Recursively converts inner files.
🌐 Web & Streaming
  • HTML Pages: Reader mode markdown conversion.
  • YouTube Videos: Automatic transcript extraction.
  • Wikipedia & RSS: Structured knowledge extract.
